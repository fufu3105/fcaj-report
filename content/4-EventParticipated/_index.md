## Overview

The three events complemented the internship project by providing perspectives beyond the implementation steps. They helped connect AWS services with system operation, security, product thinking, and professional development.

My role in all three events was **attendee**. I listened to the presentations, recorded the main ideas, discussed practical applications, and summarized lessons that could be applied to the movie recommendation project and future Cloud/AI work.

## Event 1 — AWS Cloud Sharing Session

The first event provided a broad view of modern cloud technologies. The presentations explained Docker and containers, using AWS WAF with machine learning for attack detection, real-time communication with WebSockets, graph knowledge bases with Amazon Neptune, career development in Cloud/DevOps, and effective teamwork.

The event helped me understand that cloud development requires more than infrastructure knowledge. Security, application architecture, data relationships, deployment methods, career planning, and communication skills all contribute to successful technical work.

## Event 2 — AWS Operations, Certification, and Security Sharing Session

The second event focused on operating and protecting cloud systems. The speakers discussed SLAs, meaningful monitoring metrics, the AWS Cloud Practitioner exam, and security approaches for web applications on AWS.

The most important lesson was that deployment is only the beginning of a cloud system's lifecycle. Availability, reliability, performance, logging, alerts, access control, and continuous security monitoring must be considered throughout operation.

## Event 3 — Hackathon Journey

The third event shared the experience of teams that developed technology products in hackathon and build-week environments. Topics included problem discovery, solution design, technology selection, Cloud and AI, Agentic AI, rapid prototyping, time management, and teamwork.

The event reinforced a product-oriented mindset: technology should be selected to solve a real user problem. Building a small prototype, collecting feedback, and improving it through short iterations can reduce risk and help a team use limited time effectively.

## Combined Learning Outcomes

### Technical Knowledge

- Better understood containers, cloud architecture, real-time communication, graph databases, monitoring, and web security.
- Learned how Cloud, Machine Learning, and Agentic AI can be combined in modern applications.
- Understood the importance of measurable service quality through SLAs, availability, reliability, and performance.
- Gained a clearer overview of AWS Cloud Practitioner knowledge domains and further Cloud/DevOps development paths.

### Product and Operational Thinking

- Learned to begin with user problems and business value before selecting technology.
- Understood why rapid prototyping and short iterations are useful under limited time.
- Recognized that monitoring, security, and cost control are continuous responsibilities after deployment.
- Learned that architecture decisions should consider scalability, resilience, maintainability, and operational effort.

### Soft Skills

- Recognized the importance of clear communication, active listening, and knowledge sharing.
- Learned to divide work according to team members' strengths and maintain visible progress.
- Improved awareness of time management and flexible problem solving under pressure.
- Gained additional motivation to continue learning Cloud, DevOps, AI, and system design.

## Application to the Internship Project

- Used Docker concepts when packaging the React and FastAPI application.
- Applied monitoring and security awareness when reviewing CloudWatch, IAM, and AWS Budgets.
- Considered scalability, fallback, and user experience in the recommendation-system architecture.
- Used rapid iteration when testing guest, new-user, and returning-user scenarios.
- Applied clearer task organization and documentation while completing the workshop report.

## Overall Reflection

The three events added practical context to the internship and helped me see the relationship between technology, operations, products, and people. They strengthened the knowledge used in the project while also identifying skills that require further development, especially cloud operations, security, system design, and teamwork.
